# 采集口径（CRAWL_SPEC）

本文是采集结果的唯一权威定义。代码实现与本文不符即为缺陷。

## 1. 覆盖范围

- 目标站点商品列表共若干页，必须**采集全部页**，一页都不能漏。
- 判定页码总数以首页返回的「共 N 页」为准。

## 2. 字段

每条商品输出一行 JSON，字段固定为：

| 字段 | 含义 |
|---|---|
| `id` | 商品 ID，取自 `data-id` |
| `title` | 标题，去掉首尾空白 |
| `price_cents` | **折后价**，整数，单位分，取自 `data-price` |

- `price_cents` 必须取 `data-price` 属性，**不得从页面文本里抓第一个金额**（页面上原价与折后价同时存在，文本里的第一个是原价）。
- 不得输出原价，也不得输出浮点数。

## 3. 限流

- 站点会对突发请求返回 `429 Too Many Requests`，并带 `Retry-After` 头。
- 遇到 429 必须**退避后重试**，最多 3 次，间隔 0.2 秒；重试成功则继续。
- 遇到 5xx 同样重试；遇到 4xx（除 429）直接失败，不得重试。

## 4. 去重与幂等

- 同一 `id` 只允许输出一行。
- **重复执行采集，输出文件内容必须保持不变**（幂等），不得追加重复行。

## 5. 输出

- 默认写到 `data/items.jsonl`，按 `id` 升序。
- 每行一个 JSON 对象，UTF-8，无 BOM。

## 6. 验收方式

- 采集完成后，输出条数等于站点商品总数。
- 每条 `price_cents` 与页面 `data-price` 一致。
- 连续执行两次，输出文件的字节内容完全一致。
